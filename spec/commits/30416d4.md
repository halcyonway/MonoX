# 30416d4 — feat(ui): Textual 全屏 TUI channel

新增 `extensions/channels/textual_chat.py` —— 类 Claude Code 的全屏 TUI channel。

**灵感**：[Elia](https://github.com/darrenburns/elia) — Textual + Markdown widget + VerticalScroll + TextArea。

**组件**：

- `Header` / `VerticalScroll` / `TextArea` / `Footer` + 自定义 `StatusBar` / `DebugPanel`
- `AssistantMessage(Markdown)`：流式 token + `call_after_refresh` 节流到 ~16fps
- `ReasoningMessage`：灰色 italic，冻结时机同 TerminalChannel
- `ToolCard`：cyan border，args 写入 + 结果回填

**关键 fix**：

- `@work(exclusive=True, group="drain")` 装饰 drain worker — 跑在 App 同 loop，避免跨 loop asyncio.Queue 失效
- `AssistantMessage.update()` override：抑制空 markdown update，消除与 `_on_mount` 的 race
- `StatusBar` 加 `state_text` property（Static 8.x 不暴露 `renderable`）

**Key bindings**：

- F12 → toggle DebugPanel
- Ctrl+C / `exit` → 干净关闭

**依赖**：`textual>=0.80`（实际 8.2.8）。

**验证**：7 个 smoke test（`tests/test_textual_channel.py`）pass；e2e 4/4 不回归。

**已知保留问题**：engine 不响应 channel 关闭，exit 后用户需再 Ctrl+C（与 TerminalChannel 一致，留到 `requirements/shutdown.md` 解决）。
