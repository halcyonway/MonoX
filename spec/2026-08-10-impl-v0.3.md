# 2026-08-10 v0.3 迭代

## 触发原因

跑通真实 LLM（MiniMax / api.minimaxi.com）后，terminal 输出有几个问题：

```
[state: thinking]

[state: thinking]              ← 重复
<think>
用户用中文打招呼，我应该用中文回复。   ← reasoning 污染
</think>

你好！我是 MonoX...           ← 流式输出
[state: wait_io]
<think>
...                          ← 重复
</think>

你好！我是 MonoX...           ← FinalMessage 重复打印
```

## 本轮改动

| 改动 | 说明 |
|---|---|
| `LlmChunk.delta_reasoning` | 分离 o1 / DeepSeek-R1 等内部推理 |
| `ReasoningChunk` StreamEvent | channel 决定是否显示 |
| `OpenAIStreamProxy._parse_chunk` | 提取 `reasoning_content` / `reasoning` |
| `engine._react` | emit `ReasoningChunk`，让 channel 决定 |
| `engine.run` | 不再重复 emit `StatusChange(thinking)` |
| **terminal 移到 extensions** | `core/channel/terminal.py` → `extensions/channels/terminal.py` |
| **terminal 输出重写** | 去状态噪音 / 不重复 final / 过滤 reasoning / 截断长输出 |

## 架构边界调整

**v0.2**:
- `core/channel/{base,terminal}.py`

**v0.3**:
- `core/channel/base.py` — Channel interface（核心契约）
- `extensions/channels/terminal.py` — Terminal adapter（具体实现，跟 skill 同级）

理由：core 留稳定内核；adapter 跟 skill / cli 一样放 extensions，独立迭代。

## 新 Terminal 输出

```
你好！我是 MonoX。
  > bash(cmd="echo hello && pwd")
    hello
    /Users/jialiang
  [1 tools, 120ms]
```

- TokenChunk: 流式
- ToolStart: `  > name(args)`
- ToolEnd: 缩进 + 截断（> 50 行显示前 49 + "..." + 隐藏行数）
- FinalMessage: 仅 metrics 摘要（`[N tools, Tms]`）+ 空行分隔
- ReasoningChunk / StatusChange / MetricChunk / Card / ErrorEvent: 静默

## core 边界更清晰

```
core/                  # 稳定内核（不大改）
├── protocol/         # interface + 事件 schema
├── channel/base.py   # Channel interface
├── gateway/          # 双 pump 桥接
├── sandbox/          # BashRunner
├── llm_proxy/        # OpenAIStreamProxy
├── memory/           # FsMemoryStore
├── loop/             # engine + context + checkpoint + tool registry + 内置 tool
└── config.py

extensions/            # 跟 core 解耦，独立迭代
├── channels/
│   └── terminal.py   # Terminal adapter
└── skills/
    └── memory-write/ # 业务能力（skill 目录）
```
