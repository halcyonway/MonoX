# 9004dab — feat(v0.2): wait_io as builtin tool + queue aggregate + config templates

**wait_io 内置**

- tool `wait_io(seconds)`：return `{status: "wait_more" | "done"}`
- engine 调度后停在该 tool_result，进入下一 turn（而不是工具内部自旋消耗 token）
- 解决：长跑测试 / 编译等待类任务不再每 5s 烧一次 LLM 调用

**queue_aggregate**

- 同一 turn 内连续 user message 累积到一次 LLM 调用（避免每条消息独立一轮）
- config `[loop] aggregate_user_messages = true`

**config 模板**

- `config.example.toml` 拆分：core 字段 / loop 调参 / llm extras / memory path
- 顶层注释「最小可用 config」vs「全字段 config」
