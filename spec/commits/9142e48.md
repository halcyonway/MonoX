# 9142e48 — feat(v0.6): config-driven extra_params for LLM API

Provider-specific 参数透传机制：

```toml
[llm]
extra_params = { reasoning_split = true, temperature = 0.7 }

[llm.options]
top_p = 0.95
```

- `LLMConfig` 加 `extra_params: dict` / `options: dict`
- `OpenAIStreamProxy.stream` 在 payload 里 `update(extra_params)` → `update(options)` → `update(call options)`
- 后者覆盖前者（runtime 调高优先于 config 调低）
- README 文档化「provider 特异参数怎么传」

core 仍不知道具体 key — `dict[str, Any]` 透传。
