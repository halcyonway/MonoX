# 7af46e7 — fix(loop): 纯对话 turn 也写 checkpoint + 支持 --session_key

**Bug**：用户「你叫什么？」→ LLM 答「我是...」→ exit → 重启 → 上下文丢失。只有触发过 tool 的 turn 才写 checkpoint。

**根因**：`checkpoint.save()` 只在 tool dispatch 分支调用，纯 final message 路径漏写。

**修**：

- `core/loop/engine.py` final → wait_io 分支加 `checkpoint.save(...)`
- 验证：`tests/test_e2e.py` 新增 `test_chat_only_persists_across_restart`，4/4 pass

**--session_key CLI**

- 默认 `default`，多 session 隔离（每个 session_key 一份 checkpoint / memory）
- `dataclasses.replace(cfg, session_key=...)` 覆盖

用法：`uv run python run.py --session_key myproj`。
