# 25ab1c8 — chore: gitignore config.toml

`config.toml` 是用户本地个人配置（LLM api_key / session_key / path 等），不该入 repo。

- `.gitignore` 加 `config.toml`
- `git rm --cached config.toml`（本地文件保留）
- `config.example.toml` 作为模板继续留在 repo

新用户 onboarding：
```bash
cp config.example.toml config.toml
# 编辑填入 api_key
```
