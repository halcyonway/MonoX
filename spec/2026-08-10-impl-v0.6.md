# 2026-08-10 v0.6 迭代

## 触发原因

v0.5 我把 `reasoning_split: true` 硬编码到 OpenAIStreamProxy payload，hack 不优雅。
用户提议用 config 透传机制替代。

## 设计

新增 `[llm.extra_params]` 段，OpenAIStreamProxy 原样 merge 到 API payload：

```toml
[llm]
api_base = "..."
api_key = "${MINIMAX_API_KEY}"
model = "MiniMax-M2.7"

[llm.extra_params]
reasoning_split = true   # 透传给 API
```

```python
# OpenAIStreamProxy.stream
payload = {"model": ..., "messages": ..., "stream": True}
payload.update(cfg.extra_params)    # 模型特定参数
payload.update(cfg.options)         # 默认 sampling 参数
if options: payload.update(options) # 调用方覆盖
```

## 合并优先级

```
cfg.extra_params < cfg.options < 调用方 options
```

- `extra_params`：模型特定静态参数（reasoning_split / cache_control / ...）
- `options`：默认 sampling 参数（temperature / top_p / max_tokens）
- 调用方 options：运行时透传（harness 层用）
