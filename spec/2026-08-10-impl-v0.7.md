# 2026-08-10 v0.7 迭代

## 触发原因

v0.6 用户反馈：
1. **删不掉第一个字符**：Rich 的 `console.input()` 流式输出后 prompt 位置错乱
2. **UI 不好看**：input 缺完整 line editing / history

## 选型

**prompt_toolkit**（Python 终端 line editor 事实标准）：
- 完整 line editor（光标移动、删除、history 上下、自动补全）
- 异步支持（`prompt_async`）
- `patch_stdout` context manager：其他 stdout 写入时不破坏 prompt
- FileHistory 持久化

不用 Textual（更重，本场景不需要全屏 TUI）。

## 改动

- `pyproject.toml`: `prompt_toolkit>=3.0.53`
- `extensions/channels/terminal.py`:
  - 用 `PromptSession` + `patch_stdout` 替换 `console.input()`
  - `FileHistory` 持久化到 `~/.monox/history`
  - cyan ❯ prompt（用 FormattedText）
  - exit / quit / Ctrl+C 优雅退出

## 之前 vs 现在

| 之前 | 现在 |
|---|---|
| `Rich Console.input()` | `prompt_toolkit PromptSession` |
| 删不掉第一个字符（光标位置错） | 完整 line editing |
| 无 history | 持久化到 `~/.monox/history` |
| 流式输出污染 prompt | `patch_stdout` context 隔离 |
