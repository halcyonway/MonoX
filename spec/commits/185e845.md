# 185e845 — fix(terminal): Rich 输出 ANSI 在 patch_stdout 下被吞

**Bug**：thinking spinner 显示乱码（`?[2K?[3;38;5;244m...`），ANSI escape codes 全部成可见字符。

**根因**：

- prompt_toolkit 的 `patch_stdout()` 包裹 `sys.stdout` 为 `StdoutProxy`
- Rich `Console(file=sys.stdout)` 拿到的 proxy 检测 `isatty()` → 返回 False → 走 no-tty 分支 → strip ANSI

**修**：

- 写 `_RichStdout` 类包 `sys.__stdout__`（绕过 patch_stdout proxy）
- Rich `Console(file=_RichStdout())` 拿真 stdout 的 tty 状态

```python
class _RichStdout:
    def write(self, data): return self._f.write(data)
    def isatty(self): return self._f.isatty()
```

副作用：必须 `unpatch_stdout()` 在用户输入提示符显示前，否则输入也乱码。
