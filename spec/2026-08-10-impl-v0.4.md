# 2026-08-10 v0.4 迭代

## 触发原因

v0.3 输出还是 plain text，太简陋。用户要"类似 Claude Code 的 terminal UI"，允许第三方包。

## 选型

**Rich**（Python 终端美化事实标准，PyPI 15k+ stars）：
- 流式 markdown 渲染（v2）
- Syntax 代码高亮（tool 输出）
- Panel / Table / Tree 等组件
- Live 动画 + Progress
- Claude Code 的 Python 等价（Ink → Rich）

不用 Textual（更重的 TUI 框架，本场景不需要）。

## 改动

- `pyproject.toml`: `rich>=15.0.0`
- `extensions/channels/terminal.py`: 用 Rich 重写
  - TokenChunk: `console.print(text, end="")` 流式
  - ToolStart: Panel（cyan border，title="tool"，`name(args)` 内容）
  - ToolEnd: Syntax 高亮 stdout（monokai theme），非 0 exit 红字
  - FinalMessage: dim metrics 摘要 + 空行分隔
  - ReasoningChunk / StatusChange / MetricChunk / Card / ErrorEvent: 静默
- 输入: `console.input("[bold blue]>[/bold blue] ")`，exit/quit 优雅退出

## v0.5 计划（流式 markdown）

Rich 的 `Live(Markdown(...))` 支持实时渲染 markdown：
- TokenChunk 流式累积到 buffer
- Live 周期刷新 Markdown(buffer) 渲染

技术要点：
- 用 Live context manager 包 TokenChunk stream
- 每次 chunk 更新 buffer，Live 触发 refresh
- markdown-it-py 提供 markdown 解析（Rich 已内置依赖）
