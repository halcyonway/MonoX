# 040b732 — feat(terminal): thinking spinner + F12 切换 debug view

两个小特性同时上：

**Spinner**

- thinking 时状态行显示 `⠋ thinking`（Rich `Live(Spinner)`）
- final / tool_start 时停掉 spinner

**F12 toggle debug**

- prompt_toolkit `KeyBindings` 注册 F12 → 切 `self._debug`
- F12 后：tool args / metric / state 行出现
- 再按 F12：恢复正常 mode

`run.py` 默认 `debug=False`（已通过 `--debug` 启动 debug 时 F12 关 debug）。
