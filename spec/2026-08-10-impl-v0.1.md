## 关键实现决策

### Protocol 层（最稳定）
- 所有事件 `@dataclass(frozen=True)`，不可变
- `StreamEvent = Union[TokenChunk, ToolStart, ToolEnd, ...]` 用 typing.Union（PEP 604 在 3.9 不可用作 module-level type alias runtime 求值）
- `Protocol` + `runtime_checkable` 让 interface 可被 isinstance 检查

### Channel / Gateway
- Channel 暴露双向接口：`listen()` async generator + `send(event)`
- Gateway 双 pump 设计：inbound 推 input_queue，outbound 读 output_queue → Channel.send
- TerminalChannel 用 `loop.run_in_executor(sys.stdin.readline)` 读 stdin（避免阻塞 event loop）

### Sandbox / Tool
- `BashRunner` 抽象 subprocess + timeout + cwd，未来切 docker exec / ssh 不动 interface
- 内置 tool：`bash` / `skill_load` / `read_tool_result_budget`（业务能力全部走 skill + CLI）
- `read_tool_result_budget` 内嵌 dict 做 budget store（v0 简单实现，重启可丢）

### LLMProxy
- httpx async stream，对齐 OpenAI-compatible SSE
- `_parse_chunk` 把 OpenAI delta 转 LlmChunk
- v0 内部无 retry/fallback，只调一个模型

### Memory
- `FsMemoryStore` 实现 `read_index` / `write_note` / `update_index`
- 目录：`memory/<session_key>/{Memory.md, notes/}`

### Loop Engine
- 状态机：`idle → thinking → tooling → idle`（v0 不实现 run-time interrupt cancel）
- `_react` 循环里 `_merge_tool_calls` 按 index 合并 OpenAI 流式 tool_calls
- 每 step 触发 `compress_tool_result`（L1：stdout > 4000 字符截断，原始入 budget）
- 每 step 落 `JsonlCheckpointStore`（`asyncio.to_thread` 不阻塞 event loop）
- inbound.interrupt 事件 v0 忽略（架构留位，后续迭代加 cancel 机制）

### Skill
- `extensions/skills/memory-write/` 示例，SKILL.md + scripts/save_note.sh
- Skill 全部是 shell 脚本 + 元数据，不 import core Python

### 验证
- `tests/test_e2e.py`：Mock LLM（两次调用）+ MockChannel + 真实 BashRunner
- 跑通 11 个事件 + Checkpoint 写入 + L1 压缩

## 踩过的坑

1. **PEP 604 module-level 不兼容 3.9**：`StreamEvent = X | Y` 在 3.9 runtime 求值失败，改 typing.Union。
2. **list[str[str]] 笔误**：写 type annotation 时复制粘贴出错，已修。
3. **MockChannel.listen() 退出导致 gateway pump 退出**：yield 超时后 listen() 退出会让 async for 结束。改成 stop event + 永久循环。
4. **e2e 测试 oq 双消费**：测试代码自己也 await oq.get() 跟 gateway._pump_outbound 抢。改成等 MockChannel.send 设的 final_done event。
5. **本地 Python 3.9 缺 tomllib**：用 tomli fallback（pyproject.toml 已经标 `tomli>=2.0; python_version < '3.11'`）。

## 代码风格

- 严格遵循：解耦合、少量注释、极致简化
- 所有 interface 用 `Protocol`（结构化子类型）
- 所有事件用 `@dataclass(frozen=True)`（不可变）
- Python 特性：dataclass、Protocol、typing.Union、async generator、asyncio.gather
- 第三方包：仅 httpx（async HTTP）+ tomli（3.9 fallback）
- 无 match-case（保持 3.9 兼容），用 if/elif + isinstance
