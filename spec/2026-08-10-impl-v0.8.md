# 2026-08-10 v0.8 迭代

## 触发原因

用户想要 debug 模式展示 ReAct loop 细节（thinking / reasoning / step / latency / tokens）。
类似 Claude Code：默认隐藏 debug，但有方式能看到。

## 设计

**Debug mode（v0.8 Phase 1）**：命令行 / 环境变量启用
- `uv run python run.py --debug`
- `MONOX_DEBUG=1 uv run python run.py`

debug=True 时 TerminalChannel 额外显示：
- `StatusChange`：状态切换（`⟫ thinking`）
- `ReasoningChunk`：流式累积后整体 flush（`💭 用户说...`）
- `MetricChunk`：step / latency / tools / tokens 详情
